### 📐 Tank Optimization: *the cheapest tank*

A closed cylinder of fixed volume **V** uses the least material when its derivative of surface area vanishes.

```
A(r)  = 2πr² + 2V/r
dA/dr = 4πr − 2V/r² = 0
r*    = ∛(V / 2π),   h* = 2r*
```

[Source](https://github.com/namanartist/tank-optimization)
